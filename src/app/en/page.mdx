## Keycloak Events to RabbitMQ Publisher
**Streamlining Event Publishing**

This provider lets you publish Keycloak events to a RabbitMQ server using the AMQP protocol.

- [Keycloak](https://www.keycloak.org/): An open-source identity and access management tool.
- [RabbitMQ](https://www.rabbitmq.com/): A powerful message broker.  

Check out the repository and examples:
- [Repository](https://github.com/powerimo/powerimo-keycloak)
